# FC-Barcelona-vs-Real-Madrid-Tableau-Analytics
A Tableau data visualization project comparing FC Barcelona and Real Madrid using football performance statistics from the 2023–24 season.

## Overview

This project uses Tableau to explore and compare statistical performance between FC Barcelona and Real Madrid.

The project includes interactive dashboards and a Tableau Story presenting different aspects of team and player performance, including statistical comparisons and penalty conversion analysis.

### Data

The project uses football statistics for the 2023–24 season.

The main datasets include:

FC Barcelona player statistics
Real Madrid player statistics
Penalty conversion statistics

The datasets are provided in CSV format and are used as data sources for the Tableau visualizations.

## Visualizations

The Tableau project includes:

-FC Barcelona vs Real Madrid statistical comparisons
-Player performance analysis
-Team-level comparisons
-Penalty conversion analysis
-Interactive Tableau dashboards
-A Tableau Story combining the visualizations into a structured analysis
